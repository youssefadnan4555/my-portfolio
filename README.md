
# 📦 نظام إدارة المنتجات والمبيعات المستقل (AI-02-A04)

مشروع تطبيقي برمجي متكامل ومستقل مبني باستخدام **TypeScript** و **Node.js**، يطبق مبادئ هندسة البرمجيات النظيفة (Clean Architecture) والكبسلة القوية، لإدارة المنتجات، عمليات البيع المالي، فحص المخزون، وتوليد التقارير الإحصائية.

---

## 🌟 الميزات البرمجية المنفذة (Key Features)

1. **إدارة المنتجات والمخزون:**
   - إضافة منتجات جديدة مع توليد تلقائي وفريد للمعرفات (`ID`).
   - فحص وتحديد أسعار البيع والتكلفة وحساب هوامش الربح.
   - متابعة وتحديث أرصدة المخزون بدقة وتأمين كبسلة البيانات من التعديلات الجانبية (Immutability).

2. **محرك المبيعات وإصدار الفواتير:**
   - معالجة طلبات البيع لعدة عناصر دفعة واحدة في معاملة موحدة.
   - التحقق اللحظي من توفر الكمية المطلوبة في المخزون واعتراض الطلبات المخالفة.
   - تسجيل حركات البيع، إصدار أرقام إيصالات فريدة (`Receipt ID`)، واحتساب الإيرادات وصافي الأرباح التراكمية.

3. **البحث والتصفية متعددة المعايير:**
   - البحث بالاسم والمعرف والفئات (`Electronics`, `Clothing`, `Food`, `Accessories`).
   - التصفية بنطاق الأسعار الأدنى والأعلى.

4. **نظام التقارير الذكية وتنبيهات المخزون:**
   - تقرير مالي شامل للإيرادات، الأرباح، وعدد المعاملات.
   - تحليل توزيع الوحدات المباعة حسب الفئات.
   - نظام إنذار فوري للمنتجات منخفضة المخزون (`LOW`) والحرجة (`CRITICAL`).

5. **فحص المدخلات وإدارة الاستثناءات المخصصة:**
   - التحقق الصارم من صحة البيانات باستخدام استثناءات مخصصة (`ProductValidationError`, `InsufficientStockError`).
   - معالجة احترافية للأخطاء باستخدام كتل `try / catch`.

## 🚀 تعليمات التثبيت والتشغيل (How to Run)

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. تجميع ملفات TypeScript:
```bash
npm run build
```

### 3. تشغيل التطبيق الرئيسي:
```bash
npm start
```

### 4. تشغيل حزمة الاختبارات الآلية (14 اختباراً):
```bash
npm test
```
