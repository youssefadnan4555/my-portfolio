# Terminal & Execution Basics (AI-01-A02)

## Overview
Documentation of terminal commands, directory navigation, and TypeScript script execution for the project environment.

## Key Terminal Commands Executed:
- `pwd`: Used to check and display the current working directory path.
- `ls`: Used to list all files and subdirectories within the project folder (`index.html`, `app.ts`, `style.css`, `README.md`).
- `cd`: Used to navigate smoothly between relative and absolute directory paths.

## TypeScript Execution & Testing:
- Verified compilation and execution of TypeScript files using the installed TypeScript compiler and Node.js runtime environment.
- Tested file outputs and ensured error-free terminal responses.
